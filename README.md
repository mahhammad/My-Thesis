# پروژه پایان‌نامه — قالب دانشگاه تهران

این مخزن بر پایه قالب [tehran-thesis](https://github.com/sinamomken/tehran-thesis) تهیه شده است.
هدف این مرحله **آماده‌سازی قالب برای نگارش و مدیریت نسخه‌ها** است؛ محتوای نمونه
فصل‌ها هنوز متن پایان‌نامه نیست. راهنمای اصلی قالب در [`README.upstream.md`](README.upstream.md)
و مجوز نرم‌افزار اولیه در [`LICENSE`](LICENSE) نگهداری شده‌اند.

## دفتر پژوهش و تصمیم‌های علمی

استدلال‌ها، شواهد مثبت/منفی، فرضیه‌های باز و مسیر تصمیم‌گیری معیارها و سیاست‌ها در [دفتر پژوهش (Research Journal)](research_journal/README_FA.md) نگهداری می‌شوند. [یادداشت ۸ نوامبر ۲۰۲۶](research_journal/2026-11-08-metrics-margin-fixed-centers.md) بحث I، سه R، NLL، حاشیه، جهت حرکت در فضای توزیع‌ها و سیاست‌های هم‌مرکز را ثبت می‌کند. این یادداشت‌ها جایگزین نتایج رسمی یا اثبات‌ها نیستند.

## ساختار

- `main.tex`: فایل اصلی و محل انتخاب فصل‌ها و پیوست‌ها.
- `tex/chapter1.tex` تا `tex/chapter5.tex`: محتوای فصل‌ها؛ در گام بعد فصل سوم بازنویسی می‌شود.
- `tex/appendix1.tex` تا `tex/appendix3.tex`: پیوست‌های نمونه، قابل جایگزینی با اثبات‌ها.
- `tex/faTitle.tex` و `tex/enTitle.tex`: مشخصات، عنوان و چکیده (فعلاً نمونه/جای‌نگهدار).
- `tex/commands.tex`: بسته‌ها، قلم‌ها و محیط‌های قضیه/اثبات.
- `tex/tehran-thesis.cls`: کلاس اصلی قالب؛ برای حفظ ظاهر دانشگاه فعلاً تغییر نکرده است.
- `tex/MyReferences.bib`: کتاب‌نامه نمونه.
- `img/`, `code/`: تصاویر و نمونه کد.

## پیش‌نیازها و ساخت

نیاز به XeLaTeX و مجموعه بسته‌های XePersian، `persian-bib`، `glossaries`،
`latexmk`، `bibtex8`، `xindy` و `makeindex` است. بعضی نصب‌های TeX Live ممکن است
ماژول زبان فارسی `xindy` را جداگانه نیاز داشته باشند.

قالب پیش‌فرض از قلم‌های موجود در پوشه `font/` استفاده می‌کند. فایل‌های قلم در
این بسته قرار نگرفته‌اند؛ دستورالعمل `font/README.md` را ببینید.

از ریشه پروژه:

```bash
latexmk -pdf main.tex
```

این دستور با تنظیمات `latexmkrc` از XeLaTeX استفاده می‌کند. راه جایگزین،
اجرای `bash build.sh` با همه پیش‌نیازهای نصب‌شده است.

برای پاک‌سازی فایل‌های موقت:

```bash
latexmk -c main.tex
```

## وضعیت آماده‌سازی

- ساختار و فایل‌های قالب اولیه نگهداری شده‌اند؛ متن نمونه فصل سوم هنوز تغییر نکرده است.
- گزینه قدیمی `localise=on` که در XePersian جدید خطا می‌داد، از `tex/commands.tex` حذف شده است.
- اطلاعات نمونه دانشجو در صفحات عنوان به جای‌نگهدارهای عمومی تبدیل شده‌اند.
- فایل‌های تولیدی LaTeX و فایل‌های قلم از Git مستثنا شده‌اند.
- یک اجرای اولیه XeLaTeX با قلم‌های **نسخه اصلی محلی** موفق بوده است.
  این بررسی به معنای موفقیت چرخه کامل کتاب‌نامه/واژه‌نامه نیست؛ `xindy`
  در محیط بررسی موجود نبود.

**پیش از انتشار یا تحویل:** مقطع تحصیلی، مشخصات صفحات عنوان، فهرست فصل‌ها،
محتوای نمونه، مراجع و اعتبار قالب با دستورالعمل روز دانشکده بررسی شوند.
