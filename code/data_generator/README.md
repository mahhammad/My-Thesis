# مولد داده مصنوعی / Synthetic data generator

مولد کوچک و مستقل از الگوریتم گشت یا آموزش سیاست؛ فقط `numpy` نیاز دارد. تمام تنظیمات از `config.json` خوانده می‌شوند.

```bash
python -m pip install numpy
python code/data_generator/generate.py --config code/data_generator/config.json --out generated_data
python -m unittest discover -s code/data_generator -p 'test_*.py' -v
```

## تنظیمات JSON

- `class_priors`: توزیع کلاس‌ها `K` مؤلفه‌ای و مجموع یک.
- `means`, `stds`: ماتریس‌های `K × D` برای توزیع گاوسی شرطی هر کلاس.
- `correlation`: ماتریس **مشترک بین کلاس‌ها**، متقارن و مثبت‌معین، با قطر یک (`D × D`). ماتریس کوواریانس کلاس `c` برابر `diag(stds[c]) @ correlation @ diag(stds[c])` است. اگر استقلال شرطی می‌خواهید ماتریس واحد بگذارید.
- `missing_percent`: درصد حذف مستقل (MCAR) برای هر ویژگی؛ یک عدد برای همه ویژگی‌ها یا آرایه `D`عضوی. درصد تحقق‌یافته در هر بار نمونه‌گیری ممکن است کمی متفاوت باشد. `100` هم مجاز است.
- `kernel_gamma`: پارامتر مثبت وزن یک‌گامی `exp(-gamma[a]*(x_a-z_a)^2)`؛ یک عدد یا آرایه `D`عضوی.
- `split_sizes`: تعداد `train`، `validation` و `test`؛ `seed` برای بازتولید داده.

**اندیس ویژگی‌ها از صفر شروع می‌شود.** اهمیت *حاشیه‌ای* ویژگی‌ها از میانگین وزن‌دار واگرایی KL متقارن میان توزیع‌های یک‌بعدی هر کلاس محاسبه می‌شود و در `spec.json` با `marginal_importance_symKL` و رتبه `marginal_importance_rank_zero_based` ثبت می‌شود. با `config.json` پیش‌فرض رتبه سه ویژگی اطلاع‌رسان `0 > 3 > 1` و ویژگی‌های نویزی حاشیه‌ای `2,4` هستند.

**نکتهٔ هم‌بستگی:** اگر ویژگی نویزی حاشیه‌ای با ویژگی اطلاع‌رسان هم‌بسته باشد، می‌تواند در تخمین مشترک `P(Y|X_observed)` اثرگذار شود؛ بنابراین «نویز حاشیه‌ای» الزاماً «بی‌اطلاع با شرط بر سایر ویژگی‌ها» نیست. در JSON پیش‌فرض نویزها با یکدیگر هم‌بسته‌اند اما با ویژگی‌های اطلاع‌رسان نه؛ این مقادیر قابل تغییرند.

## حقیقت مبنا و فایل‌ها

`train.npz`, `validation.npz`, `test.npz` فقط `x`, `mask`, `y` دارند؛ مقدار مفقود `NaN` است. برچسب `y` یک نمونه‌گیری تصادفی از مدل است و قطعی نیست.

`oracle_*.npz` دارای دو آرایه مستقل است: `posterior` برابر **توزیع واقعی پسین کلاس** `P(Y|X_observed)` با احتساب هم‌بستگی و فقدان داده؛ `q_population` برابر **توزیع برچسب مقصد پس از انتخاب یک ویژگی و یک گام در جامعه** با شکل `(N,D,K)` و فرمول تحلیلی:

\[
Q^{pop}_{x,a}(c) \propto \pi_c\,(1+2\gamma_a\sigma_{c,a}^2)^{-1/2}
\exp\left[-\frac{\gamma_a(x_a-\mu_{c,a})^2}{1+2\gamma_a\sigma_{c,a}^2}\right].
\]

هم‌بستگی بین ویژگی‌ها در این فرمول *تک‌ویژگی* ظاهر نمی‌شود، ولی در `posterior` مشترک اثر دارد. برای ویژگی با توزیع حاشیه‌ای یکسان در همه کلاس‌ها، `q_population=class_priors` است.

`finite_q_*.npz` آرایه `q_finite` با شکل `(N,D,K)` دارد که توزیع دقیق برچسب یک‌گامی روی **نمونه‌های آموزشِ مرجع** است، نه خروجی گشت مونت‌کارلو. برای نمونه‌های آموزش، خود نمونه از مقاصد حذف می‌شود؛ برای اعتبارسنجی/آزمون فقط گره‌های آموزش مقصد هستند. برای ویژگی غایب یا نبود مقصد مجاز، خروجی `NaN` است. برای اجرای چندگامی، حذف مبدأ گشت باید در کد گشت اعمال شود.

فایل‌های oracle برای صحت‌سنجی مدل مولدند و نباید هنگام آموزش سیاست یا پیش‌بینی به الگوریتم داده شوند. آزمایش نهایی باید روی test دست‌نخورده انجام شود.
