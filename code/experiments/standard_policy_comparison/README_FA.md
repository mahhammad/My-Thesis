# پیوست الکترونیکی §۴.۱۲ — مقایسه استاندارد خانواده‌های سیاست

**نوع:** بستهٔ همراه پایان‌نامه، قابل انتخاب برای تحویل مستقل از پوشهٔ توسعه‌ای؛ **وضعیت:** ۷۶ اجرای واقعی موجود، بدون بازآموزی یا تولید داده جدید در این انتقال.

این پوشه به‌صورت اختصاصی برای **§۴.۱۲ فصل چهارم** آماده شده است. برای تفسیر علمی نتایج، متن چاپی پایان‌نامه کافی است؛ برای مشاهده داده‌ها و محاسبات پشتیبان، فایل‌های این پوشه را در کنار آن تحویل دهید.

## راهنمای بازبینی

1. [PROTOCOL_FA.md](PROTOCOL_FA.md) تعریف داده، خانواده‌های سیاست، بودجه، سنجه‌ها و تفکیک سطح شواهد را توضیح می‌دهد.
2. [results/master_runs_76.csv](results/master_runs_76.csv) دفتر ۷۶ اجرا و نگاشت شناسه → بذر/خانواده/تابع هدف/گام‌ها/نتایج و نام فایل خام است.
3. [results/](results/) شامل چهار ZIP خام (۱۶+۱۲+۲۴+۲۴)، جدول سنجه‌های هندسه مراکز، پوشش سنجه‌ها و خروجی NLL/Softplus پس‌محاسبه‌ای است.
4. هر عضو ZIP JSON یک اجرای مشخص و آرشیو دارای manifest است؛ برای یافتن خروجی اجرا از ستون \`file\` جدول \`master_runs_76.csv\` و برای کنترل تمامیت عضو از ستون \`sha256\` استفاده کنید.
5. فایل [results/center_only_metrics.csv](results/center_only_metrics.csv) شامل ۷۶ ردیف و ماتریس‌های جفتی مرکز است؛ \`coverage_manifest_76.json\` وضعیت \`measured / not_measured / not_applicable / not_verified\` را به ازای اجرا و سنجه متمایز نگه می‌دارد.

## دامنه علمی

- رأی مستقل مربوط به ۷۶ مرکز و **۸۳۶ مقدار از ۱۱ سنجه مرکزمحور** است؛ به معنای ممیزی مستقل همه سنجه‌های نمونه‌ای نیست.
- \`node\` و \`node_class\` در قرارداد فعلی تابع شروع نمونه برون‌گرافی ندارند؛ Validation آن‌ها **نامربوط/تعریف‌نشده (N/A)** است، نه صفر.
- \`R_KL\` تاریخی با \`legacy clipping\` ذخیره شده است و KL دقیق \`support-aware\` نیست؛ \`R_sqrt_JS\` میانگین جذر JSD است، نه جذر میانگین JSD.
- این ۷۶ اجرا، ۷۶ بذر مستقل داده نیستند. چهار ZIP، هزینه‌ها و تنظیمات آموزش متفاوت دارند و مقایسه باید بودجه را مشخص کند.
- از آزمون تاریخیِ دیده‌شده برای انتخاب سیاست یا \`τ\` استفاده نکنید. این جابه‌جایی هیچ داده Test تازه‌ای تولید نکرده است.
