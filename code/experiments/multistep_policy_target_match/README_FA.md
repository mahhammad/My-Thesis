# گزارش فنی و راهنمای فایل‌ها — آزمایشگاه تاریخی وارون‌سازی مراکز

**جایگاه:** ماژول آزمایشگاهی / منبع کد تاریخی؛ شواهد علمی رسمی در §۴.۱۰

## دامنه و سؤال فنی

مقایسهٔ بازیابی مرکز هدفِ دست‌یافتنی به‌وسیلهٔ تطبیق Q محلی، گرادیان دقیق Adam و آغازگر Q همراه اصلاح گاوس–نیوتن. هدف‌ها با سیاست شاهد ساخته می‌شوند؛ حلگر از سیاست شاهد برای آغاز یا بهینه‌سازی استفاده نمی‌کند. نتیجهٔ این ابزار نه گواه یکتایی و نه دست‌یافتنی‌بودن مراکز بیرونی دلخواه است.

## قرارداد پژوهشی و محدودیت‌ها

خروجی مستقل و کامل این پوشه در checkout فعلی وجود ندارد؛ داده‌های رسمی مرتبط، گزارش‌های علمی و وضعیت پذیرش باید از مطالعهٔ مقصد بررسی شوند. از حضور کد در این پوشه نباید اجرای مجدد، موفقیت عددی مستقل، دسترسی Test یا اعتبار آماری بیشتر استنباط کرد. فرمول‌ها و پارامترها در منبع Python و گزارش مقصد قابل کنترل‌اند.
