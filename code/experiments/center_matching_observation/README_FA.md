# گزارش فنی و راهنمای فایل‌ها — هستهٔ مشاهدهٔ هدایت مرکز به هدف

**جایگاه:** کد تشخیصی تاریخی؛ نه بستهٔ نتیجهٔ مستقل در checkout فعال

## دامنه و سؤال فنی

بررسی مشاهده‌ای تنظیم سیاست انتخاب ویژگی با فرافکنی ترکیب توزیع‌های Q تک‌گامی به سمت مرکز هدف و محاسبهٔ نتیجهٔ گشت چندگامی مونت‌کارلو. این ابزار نباید به‌عنوان طبقه‌بند قابل‌استقرار یا اجرای آموزشی جدید معرفی شود.

## قرارداد پژوهشی و محدودیت‌ها

خروجی مستقل و کامل این پوشه در checkout فعلی وجود ندارد؛ داده‌های رسمی مرتبط، گزارش‌های علمی و وضعیت پذیرش باید از مطالعهٔ مقصد بررسی شوند. از حضور کد در این پوشه نباید اجرای مجدد، موفقیت عددی مستقل، دسترسی Test یا اعتبار آماری بیشتر استنباط کرد. فرمول‌ها و پارامترها در منبع Python و گزارش مقصد قابل کنترل‌اند.
