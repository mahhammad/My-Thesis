# خروجی‌های پایپ‌لاین استاندارد — ثبت اجراها

این پوشه محل پیشنهادی نگهداری خروجی‌های **نسخه جدید** است؛ آرشیوهای اصلی ۷۶ اجرا دست‌نخورده‌اند.

برای هر اجرا یک پوشه مستقل با شناسه یکتا بسازید، مثلاً:

```text
results/pipeline_v1/<run_id>/
  model.json                 # خام؛ سیاست، پارامترها و provenance
  distributions.npz          # خام؛ توزیع‌ها، مراکز، شناسه مرجع
  report.json                # مشتق‌شده؛ گزارش معیارهای عمومی
  report.md                  # مشتق‌شده؛ Markdown
  experiment_report.json     # اختیاری؛ اختصاصی همان آزمایش
```

دو فایل اول تغییرناپذیرند؛ گزارش‌ها را می‌توان بدون اجرای مجدد مدل بازسازی کرد. هر اجرای جدید فقط پس از بررسی اندازه، اطلاعات حساس، checksum و صحت ارزیابی به GitHub ثبت شود. **این پوشه فعلاً خروجی اجرای جدیدی ندارد.**
