# پویایی تابع زیان و هنجار گرادیان در آموزش

این گزارش بخشی از نتایج §۴.۱۴ و مبتنی بر خروجی‌های واقعی [Run #44419173443](https://github.com/mahhammad/My-Thesis/actions/runs/44419173443) است: ۱۵۲ آموزش NumPy، هرکدام ۱۰۰ آپدیت و ۱۰۱ وضعیت. هیچ آموزش دوباره‌ای لازم نیست.

## منطق مقایسه

تابع هدف **Sigmoid-JS** و **Softplus-JS** هم‌مقیاس نیستند؛ مشتق‌های آن‌ها نیز حساسیت متفاوت دارند. در نتیجه نه مقدار Loss و نه نرم گرادیانِ دو هدف را نمی‌توان صرفاً به دلیل کوچکی مقدار مطلق مقایسه کرد. برای هر ترکیب زیان، خانوادهٔ سیاست (shared/class) و سنجه، شکل مستقلی در نظر گرفته شده است: ۸ ترکیب × دو نمایش = **۱۶ شکل**.

هر شکل شش پنل برای |A_N| = ۱، ...، ۶ دارد؛ در هر پنل شش مسیر کم‌رنگِ زیرمجموعه‌های وابسته و میانگین پررنگ آمده است. مقیاس عمودی هر پنل از دادهٔ همان پنل تعیین می‌شود؛ ارتفاع منحنی در پنل‌های متفاوت بدون خواندن عدد محور قابل مقایسه نیست.

## قرارداد نمایش

- پسوند zoom: محور خطیِ بزرگ‌نمایی‌شده برای نمایش نوسانات کوچک
- پسوند log: محور لگاریتمی برای مسیرهای با اختلاف چند مرتبهٔ بزرگی
- محور افقی: ۰ تا ۱۰۰ آپدیت واقعی؛ بدون اتصال ساختگی اجراها
- سنجه‌های Loss و gradient_l2 فقط روی Train محاسبه شده‌اند؛ Validation فقط Accuracy/BA/Precision/Recall
- مقادیر صفر نباید هنگام استفاده از مقیاس لگاریتمی به یک مقدار ساختگی تبدیل شوند
