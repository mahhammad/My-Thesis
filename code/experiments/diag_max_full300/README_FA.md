# گزارش فنی و راهنمای فایل‌ها — StreamGraph برای محاسبهٔ دقیق با حافظهٔ کنترل‌شده

**جایگاه:** زیرساخت محاسباتی تاریخی، نه گزارش اجرای جدید

## دامنه و سؤال فنی

پیاده‌سازی امید دقیق چندگامی با جلوگیری از تخصیص تنسور بزرگ مبتنی بر سه اندیس نمونه و اعمال اصلاح منع برگشت به مبدأ. در پیش‌پرواز و حل معکوس §۴.۱۰ از این موتور به‌عنوان کنترل و روش محاسباتی استفاده شده است؛ مزیت زمان/حافظه به سخت‌افزار و دامنهٔ آزموده‌شده وابسته است.

## قرارداد پژوهشی و محدودیت‌ها

خروجی مستقل و کامل این پوشه در checkout فعلی وجود ندارد؛ داده‌های رسمی مرتبط، گزارش‌های علمی و وضعیت پذیرش باید از مطالعهٔ مقصد بررسی شوند. از حضور کد در این پوشه نباید اجرای مجدد، موفقیت عددی مستقل، دسترسی Test یا اعتبار آماری بیشتر استنباط کرد. فرمول‌ها و پارامترها در منبع Python و گزارش مقصد قابل کنترل‌اند.
