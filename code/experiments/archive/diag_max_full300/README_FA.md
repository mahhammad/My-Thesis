# آزمایش ۳۰۰ نمونه‌ای: قطرهای کران بالای آزاد و حل معکوس بوت‌استرپ

**دامنه:** آزمایش تکمیلی، نه مدل یادگیری نهایی. تمام ۳۰۰ نمونه آموزش برای بازنمایی و مراکز مرجع استفاده شدند. ۹۰ نمونه اعتبارسنجی تنها بعد از ساخت سیاست‌ها ارزیابی شدند.

هدف اول: قطر [0.602378, 0.719772, 0.684546] از کران آزادشده `full_reference_bounds.json`، تقسیم مساوی باقی‌مانده بین سایر مؤلفه‌ها. هدف دوم: همان قطر ولی تقسیم غیرقطری به نزدیک‌ترین مقدار سازگار با کران پایین و بالای *تک‌مؤلفه‌ای*. رعایت این کران‌ها اثبات دست‌یافتنی بودن هم‌زمان نیست.

**تنظیمات:** `β=.4`, `λ=.8`, `H=12`، ۴۵ گام `Q` برای مقداردهی اولیه، ۳۰ اصلاح `GN` برای هر کلاس، نرخ `0.12` و آستانه `1e-8`. هیچ سقف زمان دیواری یا تلاش مجدد از سیاست خنثی در این اجرای مشخص وجود نداشت. هر سه کلاس تا سقف ۳۰ اصلاح اجرا شدند و هیچ‌یک به هدف نرسیدند.

| معیار | یکنواخت | تقسیم مساوی | تقسیم با کران |
|---|---:|---:|---:|
| میانگین JSD تا هدف | — | ۰٫۰۲۴۸۷ | ۰٫۰۰۸۰۹ |
| اطلاعات مراکز I | ۰٫۰۱۶۸۸ | ۰٫۰۹۲۰۶ | ۰٫۱۶۳۲۴ |
| پراکندگی R_JS | ۰٫۰۰۲۰۱ | ۰٫۰۱۹۱۹ | ۰٫۰۲۴۰۹ |
| دقت متوازن اعتبارسنجی | ۹۶٫۷۷٪ | ۸۵٫۲۰٪ | ۸۹٫۲۹٪ |

هدف مساوی در کلاس‌های صفر و دو کران پایین غیرقطری را نقض می‌کند و قطعا دست‌نیافتنی است. هدف دوم این نقض را ندارد، اما عدم موفقیت در ۳۰ اصلاح، دلیل ناممکن بودن آن نیست. در مقایسه اعتبارسنجی از مراکز ثابت آموزش و تصمیم کمترین JSD در هر فرض کلاس استفاده شده است. اعتبارسنجی برای انتخاب سیاست استفاده نشده است.

`stream_graph.py` ماتریس انتقال پایه هر ویژگی را مشترک ذخیره می‌کند و بازگشت به مبدأ را موقع ضرب حذف/نرمال می‌کند. آزمون `test_stream.py` همسانی خروجی دقیق، تابع هدف Q، گرادیان و پیش‌بینی این موتور با `ExactGraph` قبلی را روی زیرگراف کوچک بررسی می‌کند. هنوز ماتریس پایه متراکم `O(d n²)` است و پیاده‌سازی kNN تنک یا میلیون‌نمونه‌ای نیست.

## بازتولید

از ریشه مخزن:

```bash
python -m unittest discover -s code/experiments/diag_max_full300 -p 'test_*.py' -v
for c in 0 1 2; do
  python code/experiments/diag_max_full300/run_maxdiag.py --c "$c" --target-kind equal
  python code/experiments/diag_max_full300/run_maxdiag.py --c "$c" --target-kind bounded_equal
done
python code/experiments/diag_max_full300/run_maxdiag.py --combine --target-kind equal
python code/experiments/diag_max_full300/run_maxdiag.py --combine --target-kind bounded_equal
```

خروجی تفصیلی هر کلاس در `results/` تولید می‌شود. خلاصه نتایج انجام‌شده در `code/experiments/bayes_center_inverse/results/full300_maxdiag_compact_summary.json` نیز ثبت شده است. حافظه اوج اجرا به شکل مستقل اندازه‌گیری نشده است.
