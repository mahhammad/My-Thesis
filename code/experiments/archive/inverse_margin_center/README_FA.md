# بازیابی معکوس مراکز حاصل از آموزش حاشیه، با سه سیاست مستقل شرطی به کلاس آغازین

- منبع هدف: دادهٔ ثابت با بذر 20261102، 300 Train، 90 Validation و سیاست مشترک آموزش‌دیده با سیگموئید حاشیه τ=0.005، پنجاه گام Adam.
- اهداف: سه سطر ماتریس `history[-1]['train']['centers']` در `full300_tau0.005.json`.
- مدل معکوس: یک Z_c برای هر کلاس **فرضی نمونهٔ آغازین**؛ همان Z_c در کل گشت ثابت می‌ماند.
- هر حلگر با logits صفر شروع می‌شود؛ از Z قدیمی صرفاً برای تأیید دست‌یافتنی بودن هدف و مقایسهٔ ارزیابی استفاده می‌شود، نه مقدار اولیهٔ حلگر.
- روش: ژاکوبین مرکز نسبت به Z، گام میراشده و جستجوی خط. β=0.4، λ=0.8، H=12؛ ممنوعیت بازگشت به مبدأ در Train.
- دقت متوازن Train (300): سیاست مشترک مستقیم 86.52٪؛ سیاست‌های مستقل بازسازی‌شده 80.26٪.
- دقت متوازن Validation (90): سیاست مشترک مستقیم 97.28٪؛ سیاست‌های مستقل 93.54٪. در ارزیابی سیاست شرطی، برای هر نمونه هر سه فرضیه کلاس بدون استفاده از برچسب واقعی اجرا می‌شود.
- خطای JSD بازیابی مرکز به‌ترتیب کلاس‌ها: 6.71e-13، 1.67e-13، و حدود صفر.
- شمار پیش‌بینی‌های عوض‌شده: 29 از 300 در Train و 8 از 90 در Validation.
- Test استفاده نشد؛ Validation برای انتخاب مدل یا توقف استفاده نشد.

## بازتولید

از داخل پوشه همین آرشیو:

```bash
python study.py
```

کتابخانه‌های NumPy و PyTorch لازم‌اند. داده‌ها از فایل `code/data_generator/config.json` بازتولید می‌شوند. موتور `StreamGraph` و محاسبهٔ JSD در همین بسته از نسخه آزمایش حاشیه موجود است. فایل `inverse_class_conditional_results.json` تمام Zهای بازیابی‌شده، منحنی اصلاحات، مراکز و نتایج را ثبت می‌کند.

**محدودیت علمی:** انطباق مرکز (یک میانگین) به معنی انطباق بازنمایی‌ها یا دقت تصمیم نیست. مقایسهٔ کیفیت معماری‌ها تنها با تابع هدف و بودجه آموزش همسان معتبر است.
