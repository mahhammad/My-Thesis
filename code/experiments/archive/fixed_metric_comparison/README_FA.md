# مقایسه پنج سیاست ثابت (آزمایش بازتولیدپذیر)

این آزمایش **آموزش سیاست نیست**. برای پنج ماتریس ثابت `Z_alpha = alpha * Z_guided` با alpha برابر `0, 0.25, 0.5, 0.75, 1`، مراکز کلاس‌ها هر بار از ۳۰۰ نمونه آموزش ساخته شده و ۹۰ نمونه اعتبارسنجی و ۱۲۰ نمونه آزمون ارزیابی می‌شوند. خروجی اصلی در `results/fixed_metric_comparison.json` قرار دارد.

از ریشه مخزن، با نصب `numpy`:

```bash
python code/data_generator/generate.py --config code/data_generator/config.json --out generated_data
python code/experiments/fixed_metric_comparison/compare.py
```

تنظیمات: `seed=20261103`، `walks=300`، `beta=0.4`، `lambda=0.8`، `horizon=12`. بذر مولد داده در `code/data_generator/config.json` برابر `20261102` است. خروجی JSON با بازاجرای محاسبات دقیقاً بازتولید شد.

**ملاحظات:** تنها یک مجموعه داده و یک بذر بررسی شده‌اند. در این اسکریپت، محاسبه KL از برش عددی `1e-300` استفاده می‌کند، نه قرارداد بی‌نهایت برای ناسازگاری تکیه‌گاه‌ها. `center_MI` و `J_margin` بر اساس داده آموزش گزارش می‌شوند. نتایج آزمون صرفاً گزارش‌اند و نباید برای انتخاب سیاست یا تنظیمات استفاده شوند.
